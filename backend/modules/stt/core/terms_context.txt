# Qwen3-ASR 컨텍스트 바이어싱용 용어 목록 — 런타임 전용.
#
# terms.txt(23개)와 왜 따로 두는가:
#   terms.txt는 Whisper의 initial_prompt에 넣을 목록이라 의도적으로 짧게 유지한다
#   — 목록이 길수록 모델이 프롬프트를 그대로 받아적는 사고가 커지고, Whisper
#   프롬프트에는 224토큰 제한도 있다.
#   Qwen은 두 제약이 모두 없다. 컨텍스트 주입이 학습된 기능이라 목록형에도
#   무너지지 않고, 시스템 메시지라 토큰 여유도 크다. 실측(우리 팀 녹음 40건):
#   66개 목록으로 용어 재현율 85.5% → 92.8%, CER 7.46% → 5.62%, 속도 변화 없음.
#   그래서 여기는 넓게 담는다.
#
# ⚠️ 숫자(포트 번호 등)는 넣지 않는다 — Whisper에서 실측으로 역효과가 확인됐고
#    (없는 숫자로 잘못 끌려감), Qwen도 컨텍스트로 출력 형식/값을 제어하지 못한다는
#    게 확인됐다("숫자는 아라비아 숫자로 표기" 지시문 무효). 숫자 표기는
#    utils/korean_itn.py 후처리가 담당한다.
#
# 늘릴 때는 AI Hub held-out으로 일반 발화 회귀를 함께 확인할 것.
