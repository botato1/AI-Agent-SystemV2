#   [겹침] 이름: 발화      — 여러 명이 동시에 말한 줄. 화자 정확도에서 제외하고

# ① 도입 — 화자별 기준선
문지수: 자, 시작할게요. 오늘 안건은 회의 데이터 보관 정책이랑 서버 이전 두 가지입니다. 먼저 보관 정책부터 볼게요.
이준오: 네, 제가 지난주에 저장 용량을 확인해봤는데요. 지금 녹음 파일이랑 회의록을 합쳐서 500기가 정도 쌓여 있고, 지금 속도면 6개월 뒤에 3배가 됩니다.
김나연: 생각보다 빠르네요. 저는 오래된 녹음은 지워도 된다고 봐요. 회의록 텍스트만 남기면 용량이 15퍼센트 수준으로 줄어들거든요.
가동현: 근데 녹음 원본이 없으면 나중에 다시 분석을 못 해요. 화자 인식이 개선됐을 때 예전 회의를 다시 돌려보는 게 불가능해집니다.
이승주: 저는 절충안이 있을 것 같은데요. 최근 세 달치는 원본을 그대로 두고, 그보다 오래된 건 압축해서 보관하는 방식이요.

# ② 빠르게 주고받기 — 침묵 없는 화자 전환
김나연: 압축하면 음질이 떨어지지 않아요?
이승주: 조금 떨어지죠.
김나연: 그럼 재분석 정확도도 같이 떨어질 텐데요.
이승주: 그건 맞아요.
가동현: 아 그러면 압축은 좀 위험한데요.

# ③ 숫자
문지수: 그럼 이렇게 정리해볼게요. 보관 기간은 열두 달로 하고, 용량 상한은 2테라로 잡겠습니다. 상한에 닿으면 오래된 것부터 지우는 걸로요.
이준오: 열두 달이면 지금 기준으로 스물세 개 회의 정도 되겠네요. 괜찮을 것 같습니다.
가동현: 서버 이전은 언제 하나요? 저번에 9월 12일 얘기가 나왔던 것 같은데.
문지수: 네, 9월 12일 목요일로 잡혀 있어요. 작업 시간은 두 시간 정도 예상하고 있습니다.

# ④ 겹쳐 말하기
문지수: 다들 9월 12일 괜찮으시죠?
[겹침] 전원: 네, 괜찮습니다.
문지수: 좋습니다. 그럼 이전 작업은 그날 하는 걸로 확정할게요.
[겹침] 김나연: 그날 오전에 다른 일정이 있어서 오후에 시작하면 좋겠어요.
[겹침] 가동현: 저는 그날 백업 스크립트를 미리 돌려둬야 할 것 같은데요.

# ⑤ 결정 번복
이준오: 잠깐만요. 아까 보관 기간 열두 달로 정했는데, 다시 생각해보니 법적으로 이 년 보관 의무가 있는 자료가 섞여 있을 수 있어요.
문지수: 아 그러면 얘기가 달라지네요. 그럼 아까 결정을 번복하고, 보관 기간은 법무 확인 후에 다시 정하는 걸로 바꿀게요. 재논의 상태로 표시해두겠습니다.
이승주: 그게 맞을 것 같습니다. 용량 상한만 먼저 적용하고 기간은 보류하죠.

# ⑥ 할 일 배분 — 호명한 사람과 대답한 사람이 대본에 확정돼 있어 가장 강한 검증 근거
문지수: 그럼 마지막으로 할 일 나눌게요. 준오님은 저장 용량 추이를 그래프로 정리해서 다음 주까지 공유해주세요.
이준오: 네, 수요일까지 만들어서 올리겠습니다.
문지수: 나연님은 압축했을 때 재분석 정확도가 얼마나 떨어지는지 확인 부탁드려요.
김나연: 알겠습니다. 샘플 몇 개로 비교해볼게요.
문지수: 동현님은 서버 이전 절차랑 백업 계획을 문서로 정리해주시고요.
가동현: 네, 9월 5일까지 초안 공유드리겠습니다.
문지수: 승주님은 법무 쪽에 보관 의무 기간 확인해주시겠어요?
이승주: 네, 이번 주 안으로 답변 받아볼게요.
문지수: 좋습니다. 그럼 오늘 회의는 여기까지 하겠습니다. 수고하셨습니다.
