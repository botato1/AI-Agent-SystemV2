# 모의 회의 대본 — 알림 정책 개편 (4인, 가동현 불참)
#
# 이 대본은 **화자 인식 검증**에 초점을 맞췄다. 참석자 명단이 1명만 넘어오던
# 백엔드 버그가 고쳐진 뒤 처음 제대로 재는 회의다(직전 회의: cpCER 75.36%).
#
# 확인하려는 것:
#  ① 화자 배정 정확도 — 4명이 촘촘히 번갈아 말하는 구간을 일부러 많이 넣었다.
#  ② 짧은 맞장구가 **앞사람 문장에 붙는지** — "네.", "맞아요." 같은 한마디를
#     다른 사람이 바로 이어 받는 자리를 여러 번 배치했다. 지금은 한 청크에 두
#     화자가 들어가면 짧은 쪽이 앞사람 발언에 합쳐지는 문제가 있다(실측).
#  ③ 청크 경계 단어 잘림 — ★ 긴 구간 뒤에 바로 다른 화자가 끼어들게 했다.
#
#  ★ 표시 줄은 문장 사이에 쉬지 말고 이어서 읽는다. ★는 읽지 않으며 채점 시 제거된다.
#
# 읽는 요령
#  - 평소 회의 속도로. 빨리 읽으면 인식이 무너져 검증이 안 된다.
#  - 화자가 바뀔 때 0.5초쯤 쉰다. 단 [빠르게] 표시 구간은 **바로 이어받는다** —
#    거기가 ②를 재는 자리다.
#  - 참석자 4명(문지수·김나연·이승주·이준오)을 모두 선택하고 시작할 것.

문지수: 오늘은 알림 정책을 다시 볼까 합니다.
문지수: ★ 지난달부터 알림을 끄는 사용자가 눈에 띄게 늘었어요. 설정 화면 들어가서 전체 끄기를 누른 비율이 두 배가 됐습니다. 알림이 너무 많다는 문의도 같이 늘었고요.
김나연: 저도 그 수치 봤어요.
이승주: 어떤 알림이 제일 많았나요?
김나연: ★ 댓글 알림이 압도적이에요. 전체의 절반이 넘습니다. 그중에서도 자기가 쓴 글에 달린 댓글이 아니라 남의 글에 달린 댓글 알림이 대부분이에요. 그건 사실 안 봐도 되는 거죠.
이준오: 맞아요.
문지수: 그럼 남의 글 댓글 알림을 기본으로 끄면 되겠네요.
이승주: 네.
이준오: 잠깐만요.
이준오: ★ 그렇게 하면 커뮤니티 활동이 줄어들 수 있어요. 알림을 보고 들어오는 사용자가 생각보다 많거든요. 지난번에 알림 하나 껐다가 재방문율이 떨어진 적이 있었어요.
김나연: 아 그런 적이 있었죠.
문지수: 그럼 어떻게 하는 게 좋을까요?
이준오: 빈도를 줄이는 쪽이 나을 것 같아요.
이승주: 묶어서 보내자는 말씀이신가요?
이준오: 네 맞아요.
이승주: ★ 그건 저도 찬성이에요. 한 시간에 한 번씩 모아서 보내면 개수가 확 줄어듭니다. 사용자가 받는 알림은 하루에 서너 개 정도로 떨어질 거예요.
문지수: 좋습니다. 그럼 남의 글 댓글 알림은 끄지 않고 묶어서 보내는 걸로 확정하겠습니다.
김나연: 네 알겠습니다.
문지수: 다음은 알림 시간대인데요.
김나연: 밤에 오는 알림 불만이 많았어요.
이승주: 저도 그 얘기 들었습니다.
문지수: ★ 그러면 밤 열 시부터 아침 여덟 시까지는 알림을 보내지 않는 걸로 하죠. 급한 알림만 예외로 두고요. 이건 설정에서 사용자가 바꿀 수 있게 하겠습니다.
이준오: 급한 알림 기준은 누가 정하나요?
문지수: 아 그건 다시 봐야겠네요.
문지수: 방금 결정을 조금 바꿀게요. 예외 없이 전부 막고, 급한 알림 기준은 다음 회의에서 정하겠습니다.
이승주: 네 그게 낫겠습니다.
김나연: 저는 설정 화면 초안을 준비하겠습니다.
이준오: 저는 알림 묶는 로직을 맡을게요.
문지수: 좋습니다. 오늘 결정된 건 두 가지예요. 수고하셨습니다.
