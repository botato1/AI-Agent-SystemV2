## 6. 평균 산출 방식 (★ 반드시 명시)
슬라이드의 94.95% / 92.18%는 **위 3건의 문서별 정확도를 단순 산술평균**한 값입니다.
(스크립트가 `eval_report.json`에 자동 계산하는 "overall" 필드는 전체 글자/단어 수 기준 **가중평균**이라 이 숫자와 다를 수 있음 — 두 방식의 차이를 헷갈리지 않도록 각주에 "3건 단순평균" 표기 필요)

- 글자 정확도: (100.00 + 97.47 + 87.38) / 3 = **94.95%**
- 단어 정확도: (100.00 + 89.21 + 87.33) / 3 = **92.18%**
- CER = 100% − 94.95% = **5.05%**

## 7. 왜 차트 포함 문서는 제외했는가
차트가 포함된 문서는 OCR 파이프라인이 라벨을 그대로 읽는 대신, 차트의 값을 데이터로 재구성하도록 프롬프트가 설계되어 있음 (`vl_engine.py`의 OCR[chart] 프롬프트: "이 차트의 데이터를 마크다운 표 형식으로만 정리"). 이는 버그가 아니라 의도된 동작이므로, 원문 그대로 옮겨 적은 정답 텍스트와 문자 단위로 비교하면 정확도가 낮게 나오는 것이 당연함. 따라서 이번 정확도 측정 범위를 텍스트·표 문서로 한정.
