## 5. 표본 확대 과정에서 발견 · 수정한 버그

### 5-2. 읽기 순서(reading order) 버그
`bok_payment_report_p9`만 유독 49.62%로 낮았다. 박스형 인용문 + 2단 컬럼이 섞인 레이아웃에서, PyMuPDF가 반환하는 블록 순서(PDF 콘텐츠 스트림 순서)가 실제 읽는 순서와 어긋나는 게 원인. 파이프라인에 이를 교정하는 로직 자체가 없어서 `backend/modules/document/doc_processor/postprocess/reading_order.py`를 신규 작성했다.

세 번의 시행착오를 거쳐 완성했다:
1. **1차 (즉시 롤백)** — 블록 중심 x좌표만으로 좌/우를 나눴더니 표·단일컬럼 문서까지 2단 컬럼으로 오판. 21건 CER이 10.00%→14.12%로 악화, `bok_payment_report_p101`은 99.68%→40.31%까지 떨어져 배포 직후 원복.
2. **2차 (부분 실패)** — x0 클러스터링 + 최소 블록수 + 세로 겹침 조건을 추가했지만, "컬럼 아님 → 원래 순서 유지"라면서 실제로는 y좌표로 재정렬해버리는 결함이 남아있었다. PyMuPDF 원본 순서는 완벽한 y순서가 아닌데(예: 섹션 헤더와 다음 줄의 y값이 근소하게 뒤바뀜) 이를 건드리면서 표 형태 문서에서 다시 회귀.
3. **3차 (완성)** — 컬럼으로 판단되지 않은 구간은 입력 순서를 그대로 보존하도록 구조를 재설계. 라벨-값 표(폭 비대칭) 판별 기준, "같은 행 왼쪽에 다른 블록이 있으면 구분자 아님" 규칙을 추가해 표/단일컬럼 문서의 오탐을 제거. 실제 버그 사례를 그대로 재현하는 회귀 테스트 13개로 고정 (`test_reading_order_regression.py`).

### 5-3. 평가 스크립트 — 목차 점선(leader dots) 정규화

### 5-4. PyMuPDF span 병합 스퓨리어스 공백 버그
같은 diff 과정에서 국회 회의록 3건이 CER 기준으로도 유독 낮은 이유를 실제 span 좌표까지 파고들어 확인했다. 정답은 `"많은생각이오고갑니다"`(원문 자체에 띄어쓰기 없음)인데 파이프라인 출력은 `"많은생 각 이오고 갑 니다"`로 글자 사이에 없던 공백이 들어가 있었다. 원인은 `text_parser.py`가 같은 줄의 PyMuPDF span들을 **무조건 공백으로 합치는** 로직이었는데, PyMuPDF는 폰트가 바뀌는 지점마다(실제 글자 간격이 0이거나 겹쳐도) span을 나누는 경우가 있어서(정부 문서 특정 글자만 다른 서브셋 폰트로 렌더링) 매번 공백이 잘못 삽입되고 있었다.

span 사이 실제 x좌표 간격이 **양수(진짜 간격)일 때만** 공백을 넣도록 `_join_spans()`로 분리해 수정 — 간격이 0 이하(맞닿음/겹침)인 경우만 보수적으로 고쳤다 (임계값을 더 키우면 다른 문서의 진짜 단어 사이 공백까지 지울 위험이 있어 안전한 쪽으로 제한). 이 버그는 회의록뿐 아니라 21건 전체에 폭넓게 영향을 주고 있었던 것으로 확인 — **적용 후 21건 중 단 한 건도 하락 없이 전부 개선되거나 그대로였음.**

### 5-5. WER(단어정확도)이 왜곡되는 케이스 — 국회 회의록
회의록 4건은 CER 기준으로는 정상 범위인데 WER은 여전히 마이너스로 나온다 (5-4 수정 후에도 -133%~-140%대). 원인은 버그가 아니라 **정답 텍스트 자체(및 실제 원문)에 어절 간 띄어쓰기가 없어서** 문단 전체가 "단어 1개"로 처리되며 WER 계산이 통계적으로 왜곡되는 것. → **회의록류 문서는 CER/글자정확도만 신뢰**하고 WER/단어정확도는 슬라이드에서 제외 권장.

## 6. 왜 차트 포함 문서는 제외했는가
차트가 포함된 문서는 OCR 파이프라인이 라벨을 그대로 읽는 대신, 차트의 값을 데이터로 재구성하도록 프롬프트가 설계되어 있음 (`vl_engine.py`의 OCR[chart] 프롬프트: "이 차트의 데이터를 마크다운 표 형식으로만 정리"). 이는 버그가 아니라 의도된 동작이므로, 원문 그대로 옮겨 적은 정답 텍스트와 문자 단위로 비교하면 정확도가 낮게 나오는 것이 당연함. 따라서 이번 정확도 측정 범위를 텍스트·표 문서로 한정.
