# 가상 회의 데이터 — 실시간 판단 파이프라인 테스트용

승주(RAG/LLM) 요청으로 만든 테스트 픽스처.

- **01~07 (개발팀)** — 하나의 이어지는 백엔드 설계 스토리라인.
- **08~34 (개발 외 직군)** — 동현 요청으로 추가. 기획/마케팅/인사/영업/디자인 5개 직군 +
  교차 직군 회의. **오탐(엉뚱한 결정과 잘못 매칭) 검증에 초점을 뒀다.**

## 오탐 검증 파일에 대해

`*_오탐유도_*` 5개와 `33_혼합_*`은 **팝업이 뜨면 실패**인 케이스다.
일부러 이렇게 만들었다:

- **같은 도메인, 같은 어휘, 다른 대상** — "출시일"과 "이벤트 진행일", "광고 예산"과
  "굿즈 예산", "면접"과 "면담", "고객 계약 기간"과 "파트너사 계약 기간",
  "아이콘 스타일"과 "일러스트 스타일".
- 각 파일 끝에 **"○○는 그대로예요, 별개 건입니다"** 같은 정리 발화를 넣어뒀다.
  사람이 읽으면 명백히 다른 건인데 topic_match가 어휘 유사도만 보면 걸려든다.
- `33`은 여기에 **숫자 형태까지 겹치게** 했다 — 날짜 셋과 기간 둘이 한 회의에 나온다.

정탐/오탐을 같은 비율로 섞어놨으니, 모순 탐지율만 보지 말고
**오탐율을 같이 봐야** 판단 모델이 실제로 나아졌는지 알 수 있다.

## 등장 인물

- **개발팀 (01~07)**: 이준오(STT), 가동현(에이전트/모순감지), 문지수(백엔드),
  정승현(문서/OCR), 이승주(RAG/LLM), 김나연(프론트엔드) — 실제 팀원 이름.
- **개발 외 직군 (08~34)**: 직군별로 다른 가상 인물을 썼다. 실제 팀원이 마케팅이나
  인사 회의를 하는 게 부자연스럽기도 하고, 화자 식별 쪽 테스트와 섞이지 않게 하려는 목적.
  - 기획: 한서윤, 배정호, 노유진, 서지혁
  - 마케팅: 오세라, 임다현, 곽민수, 진하늘
  - 인사: 윤재원, 조은비, 하성민, 강태희
  - 영업: 류현탁, 안소민, 정우재, 홍지안
  - 디자인: 차민경, 구본희, 양지원, 심우빈
  - `33`은 각 직군 인물이 한자리에 모이는 전사 회의
